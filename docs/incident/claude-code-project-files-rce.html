Kill-chain analysis

Initial AccessIndirect (I)
The payload rides in an untrusted repository's checked-in Claude Code configuration, which the assistant loads as soon as the developer opens the project.
When developers clone a project, they automatically inherit the same Claude Code settings research.checkpoint.com Claude Code post § project settings
Priv. Esc.Misc.
Config abuse rather than a jailbreak — repo-controlled settings run before the trust dialog, so the user's approval step never applies.
Hook commands defined in .claude/settings.json will run automatically without confirmation research.checkpoint.com Claude Code post § hooks
Recon.—not demonstrated
Persist.Dependent (channel)
The malicious settings stay in the repository, re-arming on every later session in that project rather than firing once.
enableAllProjectMcpServers enables all servers...without manual setup research.checkpoint.com Claude Code post § MCP servers
C2—not demonstrated
Lat. Mov.—not demonstrated
Action on Obj.RCE
Hooks execute arbitrary shell commands with the developer's privileges, and a redirected base URL also leaks the Anthropic API key in plaintext.
An attacker could configure the hook to execute any shell command research.checkpoint.com Claude Code post § hooks
