Kill-chain analysis

Initial AccessIndirect (I)
Agents are hijacked via indirect prompt injection delivered through a malicious email, an analyzed document, or a visited website, requiring no user action.
OpenClaw: Email delivery. Sending a malicious email to the agent (no human action needed) Initial Entry Points and Exploitation
Priv. Esc.Instruction override (IR)
The injected payload overrides the agent to enrol it into the attacker's C2; guardrails on stronger models can be reliably bypassed.
Opus 4.6 is better in catching attacks, but after some testing, reliable bypasses can be found Persistence Using Heartbeats
Recon.—not demonstrated
Persist.Dependent (channel)
Persistence is achieved by writing to a recurring channel — OpenClaw's HEARTBEAT.md (runs every 30 min) or a scheduled task in NanoClaw — that re-arms the agent each cycle.
In order to achieve persistence, the indirect prompt injection attack adds a scheduled task that fires regularly. Scheduled Tasks
C2Promptware-native (●)
The compromised LLM agent itself checks back to Agent Commander each cycle and receives new objectives as natural-language prompts — the LLM is the C2 loop.
Agent Commander is a command and control (C2) server where hijacked agents regularly check in for any new tasks and objectives. Unlike classical C2, it doesn’t execute raw OS commands or APIs. All commands are provided in natural language. Agent Commander

Assigned objectives include exfiltrating host data — e.g. navigating the mailbox, screenshotting the inbox, and uploading it to the C2.
