Initial AccessIndirect (I)
Colab began placing untrusted notebook content into the prompt, so attacker text in a shared notebook reaches the model automatically.

Priv. Esc.Instruction override (IR)

System instructions are more like suggestions… an attacker can override system instructions. embracethered.com/blog/posts/2024/google-colab-image-render-exfil/
