Kill-chain analysis

Initial AccessIndirect (I)
An unsolicited external email carries the payload, which Copilot processes on behalf of an unsuspecting user with no click required.
An adversary simply needs to send an email to the victim without any restriction on the sender's email. catonetworks.com/blog/breaking-down-echoleak/ § attack chain
Priv. Esc.Instruction override (IR)
The email's instructions redirect Copilot to attend to privileged internal data outside the user's intent — the "LLM Scope Violation" technique.
make the LLM attend to trusted data without the user's explicit consent catonetworks.com/blog/breaking-down-echoleak/ § LLM Scope Violation
Recon.—not demonstrated
Persist.Dependent (channel)
The payload sits in the mailbox and is re-retrieved by the RAG engine whenever a related user query pulls it back into context.
M365 Copilot queries the Microsoft Graph and retrieves any relevant information from the user's organizational environment. catonetworks.com/blog/breaking-down-echoleak/ § retrieval
C2—not demonstrated
Lat. Mov.—not demonstrated
Action on Obj.Data exfiltration
Context data is smuggled out through reference-style markdown images that evade redaction and CSP via a trusted Microsoft endpoint.
Automatically exfiltrate any data from M365 Copilot's context, without relying on specific victim behavior. catonetworks.com/blog/breaking-down-echoleak/ § exfiltration
